# Booktique Ghana E-Commerce Website

A database-driven e-commerce web application developed for Booktique Ghana as part of an individual university E-Commerce course project.

## Project Overview

This project simulated a real-world freelance development engagement. I worked directly with the owner of Booktique Ghana to understand the business, gather website requirements, identify desired functionality, and translate those requirements into a working e-commerce application.

Throughout the development process, I incorporated feedback from the business owner and refined the application based on her needs and preferences.

> Note: This application was developed as an academic project and prototype. It was not deployed as Booktique Ghana's production website.

## Key Features

- Product browsing and product detail pages
- User registration and authentication
- User login functionality
- Shopping cart functionality
- Database-driven product and user management
- Email functionality using PHPMailer
- Responsive user-facing interface

## Development Process

The project involved more than the technical implementation of the website. I worked through several stages of a real client-development process:

1. Communicated directly with the business owner.
2. Gathered and documented website requirements.
3. Translated business requirements into technical features.
4. Designed and developed the application.
5. Presented progress and functionality to the stakeholder.
6. Incorporated feedback into subsequent iterations.
7. Tested the resulting application against the project requirements.
